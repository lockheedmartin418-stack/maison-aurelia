# Maison Aurelia - Haute Joaillerie & High Jewelry eCommerce

A luxury jewelry eCommerce application built with React, Vite, and Tailwind CSS.

## Features
- **Haute-Joaillerie UI/UX**: Champagne, gold, and onyx dark luxury aesthetics with serif typography.
- **The Vault Catalog**: Live filtering across jewelry categories (Rings, Necklaces, Bracelets, Earrings) and precious metals (Platinum, Yellow Gold, Rose Gold, White Gold).
- **Curated Series**: Showcase of signature collections (Lumière d'Or, Nocturne Royale, Mythologie).
- **Interactive Bag Drawer**: Real-time pricing with multi-currency toggles (USD, EUR, GBP), coupon discounts (`MAISON10`), and acquisition simulation.
- **Wishlist & Inspection Modal**: Quick-view modal with detailed stone carat specs and provenance notes.
- **Private Salon Consultation**: Booking interface for confidential in-person or virtual appointments.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the local development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
